# Progetto JavaScript - start2impact

Un progetto sviluppato nell'ambito del percorso di studi con start2impact per mettere in pratica le competenze di sviluppo web con JavaScript.

## 🚀 Live Preview
Puoi consultare la versione live del progetto direttamente su GitHub Pages:
👉 [Guarda la Live Preview](https://cristiancipriani97-ux.github.io/progetto-JavaScript-start2impact/)

## 🛠️ Tecnologie Utilizzate
* **HTML5**: Struttura semantica ed accessibile.
* **CSS3**: Layout responsive e stilizzazione.
* **JavaScript (ES6+)**: Logica applicativa, gestione delle finestre modali e manipolazione del DOM.

## 📖 Contenuti e Funzionalità
* Struttura responsive adatta a dispositivi Desktop, Tablet e Mobile.
* Interattività dinamica tramite JavaScript.
* Codice strutturato nel rispetto delle linee guida di accessibilità (screen reader).
